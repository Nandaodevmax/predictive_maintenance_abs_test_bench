# 🔧 Predictive Maintenance Project

## 📊 Overview
This project aims to predict equipment failures using operational data such as temperature, vibration, and pressure.

## 🎯 Objective
Develop a Machine Learning model capable of identifying failure patterns and supporting maintenance decision-making.

## 🧠 Techniques Used
- Data Analysis with Pandas
- Data Visualization
- Machine Learning (Decision Tree)

## 📈 Insights
- High temperature and vibration are strong indicators of failure
- Equipment with longer operating time shows higher failure probability

## 🤖 Model
A Decision Tree Classifier was used to predict failures based on input variables.

## 🛠️ Tools
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook
